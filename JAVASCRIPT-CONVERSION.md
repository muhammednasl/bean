# JavaScript / JSX conversion

This project has been converted from TypeScript/TSX files to JavaScript/JSX:
- `.tsx` files are now `.jsx`
- `.ts` files are now `.js`
- Type annotations and type-only syntax have been removed
- JSX and the existing React/Tailwind UI have been preserved

## Run locally
1. Install Node.js LTS if it is not installed.
2. Open this folder in your terminal.
3. Run `npm install`.
4. Run `npm run dev`.

Note: This is a source-level conversion. Dependencies were not installed and a production build was not run in this environment. If you encounter a build error, share it and I can help troubleshoot.
